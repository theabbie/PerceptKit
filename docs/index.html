Describe a perception goal in natural text. The agent plans corruptors, writes trainers/probes as an in-browser virtual filesystem, runs them against @theabbie/perceptkit, and exports a downloadable .pkm. Workspace clearing will generate values only; weights are saved locally in your browser.

Digit classifier

Synthetic 8×10 font digits with random shifts and salt noise are generated; a tiny transformer (~9k params) is trained with per-token one-hot outputs. Draw your own digit below after training.

Text-overlap scorer

Documents rendered as line-art; corruption shifts one line into another (overlap). Trained by pairwise ranking — mild vs severe corruption of the same base doc. Higher score = cleaner layout.

Colorizer

Synthetic scenes (sky gradient, sun, hills, water) generated in the browser. Model sees only Rec.601 grayscale; the dense head predicts the full RGB patch per token — i.e. it must invent color from luminance + context.
